# UA Region Scraper

Скрапер для збору даних про компанії з сайту UA-Region за КВЕДами.

## Особливості

- Асинхронний HTTP клієнт з експоненційними затримками та механізмом повторних спроб
- Збереження даних у базу даних SQLite або PostgreSQL
- Конкурентна обробка сторінок з обмеженням навантаження
- Стійкість до блокування з "людськими" затримками та обертанням User-Agent
- Механізм блокування для запобігання одночасному запуску кількох екземплярів
- Контрольні точки для відновлення роботи після переривання
- Підтримка виявлення та обходу CAPTCHA та honeypot пасток
- Повна типізація з використанням Python type hints

## Вимоги

- Python 3.8 або вище
- Встановлені залежності з `requirements.txt`

## Встановлення

```bash
# Клонування репозиторію (якщо з Git)
git clone https://github.com/yourusername/ua-region-scraper.git
cd ua-region-scraper

# Встановлення залежностей
pip install -r requirements.txt
```

## Використання

### Скрапінг окремого КВЕДу

```bash
python main.py -k 53.20
```

### Скрапінг всіх КВЕДів

```bash
python main.py -a
```

### Виведення списку доступних КВЕДів

```bash
python main.py -l
```

### Додаткові опції

```bash
python main.py -h
```

Покаже всі доступні опції:

```
usage: main.py [-h] [-k KVED | -a | -l] [-v] [-f]

Скрапер компаній за КВЕДами з сайту UA-Region

options:
  -h, --help            show this help message and exit
  -k KVED, --kved KVED  Конкретний КВЕД для скрапінгу
  -a, --all             Обробити всі КВЕДи з конфігурації
  -l, --list            Список доступних КВЕДів
  -v, --verbose         Детальне логування
  -f, --force           Примусово запустити, ігноруючи блокування
```

## Структура проекту


## Налаштування

Основні налаштування знаходяться у файлі `config.py`. Ви можете змінити наступні параметри:

- Список КВЕДів для скрапінгу
- Параметри HTTP запитів
- Шляхи збереження даних
- Параметри затримок та повторних спроб
- Параметри бази даних

## Дані

Дані зберігаються у базі даних SQLite за замовчуванням у файлі `companies.db`. Ви можете налаштувати використання PostgreSQL у файлі конфігурації.

Кожен запис компанії містить:
- Назва
- Адреса
- Телефон
- Email
- КВЕД
